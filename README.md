# Assignments for EAPS 507 – Fall 2026

This repository contains my completed Jupyter Notebook assignments for EAPS 507 at Purdue University during Fall 2026. The notebooks demonstrate Python methods for exploring, processing, and analyzing scientific data.

## Assignments

| Notebook | Description |
| --- | --- |
| [Pandas Data Manipulation](EAPS507_Pandas_Data_Manipulation_1013.ipynb) | Uses Pandas to explore geographic features in Indiana. Covers data loading, indexing, Boolean filtering, missing values, grouping, summary statistics, sorting, date handling, and a final data-analysis challenge. |
| [Xarray 10-Minute Beginner Tutorial](Xarray_10_Minute_Beginner_Tutorial_Completed.ipynb) | Uses NumPy and Xarray to construct a small synthetic weather dataset, select data by coordinates and position, calculate temperatures across named dimensions, and make plots. Includes the completed Section 6 practice exercise. |

## Tools

- Python 3 and Jupyter Notebook
- Pandas and NumPy
- Xarray and Matplotlib

## Reproducibility notes

The notebooks retain code cells and saved outputs so that the calculations and results can be reviewed on GitHub.

- **Xarray tutorial:** Generates synthetic weather data using a fixed random seed (`42`), so no external dataset is needed.
- **Pandas tutorial:** Reads `IN_Features_20140204.txt`, a pipe-delimited geographic features dataset. The original data file is **not included** in this repository. Its previously saved notebook outputs are viewable, but rerunning that notebook from the start requires obtaining the original dataset and placing it alongside the notebook.

Git commit history documents changes to the assignments and repository documentation over time.
